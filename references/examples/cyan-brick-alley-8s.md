无字幕、无水印、无LOGO、无BGM，仅保留环境音效与人物台词。

【风格定调】
视觉风格：日系清新胶片风，静谧自然生活感。画面柔和，颗粒质感明显，自然光为主，无人工补光痕迹。

色彩基调：暖黄米白为主色调，阴影偏棕绿，高光不过曝，整体低饱和、高明度，如午后阳光透过窗帘。
特效禁令：禁止数字光效、霓虹光晕、人工色彩叠加特效。

【角色 / 道具 / 场景引用】
角色参考：
主角 img:1，暂无音频 作为主角音色参考。
道具参考：
虚拟面板 暂无参考图
场景参考：
青砖巷弄 img:0

【全局前置条件】
时间：午后，阴天，天光柔和漫射。
环境：中式传统青砖巷弄，两侧高耸砖墙墙面斑驳带水渍痕迹，地面平整石板散落几片枯叶，巷底隐约可见绿色树丛。自然漫射光均匀笼罩整条巷弄，无直射阳光，整体灰绿暖灰色调，空气安静湿润，胶片颗粒均匀覆盖画面。
空间关系：主角身着黑白机械装甲站立于巷弄中段偏右位置，面朝巷弄纵深方向；左侧青砖墙面为主角正前方，虚拟面板将浮现于该墙面上；光源来自巷弄上方天光漫射，无明确方向性直射光。

【镜头描述】

【镜头1 · 0–2s · 固定中景 · 虚拟面板浮现于青砖墙面】
机位架设于主角斜后方约两步距离，固定中景拍摄巷弄纵深与主角背影侧面。
画面内容：斑驳的青砖墙面上，一片半透明白色光面缓缓浮现，光面边缘柔和如磨砂玻璃，呈横向矩形，悬浮于砖墙表层，与粗糙砖面形成质感对比。面板内部为空白状态，微微泛着暖白色柔光，与巷弄灰绿色调交织融合。主角侧身站立于画面右下方，黑白配色机械装甲的肩部齿轮装饰和白色披风边缘微微入画，身体静止未动。午后漫射天光从巷弄上方均匀洒落，青砖墙面呈现灰绿暖灰色调，地面石板上的枯叶纹路清晰可见，胶片颗粒柔和覆盖全画面，整体低饱和高明度。
环境音：巷弄深处隐约的风声、枯叶被微风吹动的沙沙声、面板浮现时极轻的电流嗡声。

【镜头2 · 2–3.5s · 缓慢推近中近景 · 主角转头凝视面板】
机位从斜后方缓慢推近至中近景，拍摄主角侧脸与面板。
画面内容：主角缓缓将头转向左前方墙面上的虚拟面板，多角尖刺头盔随之转动，护目镜眼部白光映出面板的暖白色柔光，目光聚焦于面板中心。主角身体保持静止，仅头部转动，胸口巨大齿轮轮盘在装甲上微微反射环境光。白色披风随转头动作轻轻摆动，金银暗纹在漫射光下若隐若现。面板静静悬浮于青砖墙面上，仍为空白状态，边缘光晕稳定柔和。漫射天光均匀照亮主角半边侧脸，黑白装甲的金属质感与皮革衬里细节清晰保留，暗部层次丰富，胶片颗粒在逆光区域尤为明显。
环境音：主角装甲关节轻微的金属摩擦声、面板持续的低频嗡声、巷弄深处风声。

【镜头3 · 3.5–6s · 固定近景 · 面板显示文字后变红闪烁】
机位架设于主角侧前方，固定近景拍摄面板全貌与主角虚化侧脸。
画面内容：面板中央浮现深灰色文字"任务失……"，字体简洁无衬线，横向排列，字迹沉稳。文字停留约半秒后，面板整体色调骤然转为暗红，边框由暖白变为深红色，文字"任务失……"消融为三个红色感叹号"！！！"，字体放大，颜色鲜红，面板表面泛起轻微红色脉动光纹。主角护目镜眼部白光中映出红色光芒，头盔尖角轮廓在红光映照下更显凌厉，身体微微绷紧，披风垂落不动。红色光芒在主角装甲黑白表面投下淡淡红光反射，与巷弄灰绿砖墙的冷调形成冷暖对比。面板红色脉动持续约一秒，青砖墙面被红光短暂染上一层暖色。
环境音：面板变红时短促的电子警示音、红色脉动伴随的低频心跳般嗡鸣、主角装甲细微的金属紧绷声。

【镜头4 · 6–8s · 固定近景 · 面板恢复正常显示"任务完成"】
机位保持不变，固定近景拍摄面板与主角虚化侧脸。
画面内容：面板红色光纹迅速消退，边框回归暖白色柔和光晕，整体色调恢复为半透明白色。面板中央文字重新浮现，变为深灰色"任务完成"四字，字体与此前一致，横向排列，字迹清晰沉稳。主角护目镜中红色光芒褪去，恢复为白色光芒，身体微微放松，披风轻轻垂落归位。漫射天光重新主导画面色调，灰绿暖灰回归，青砖墙面的斑驳水渍细节重新清晰，胶片颗粒柔和覆盖全画面，巷弄归于午后静谧。
环境音：面板恢复时轻柔的电子提示音、面板低频嗡声渐弱、巷弄深处风声与枯叶沙沙声回归。

【转场方式】
匹配剪辑（Match Cut）：镜头1至镜头2通过主角头部转动的动作连贯性自然过渡；镜头2至镜头3、镜头3至镜头4均为同一机位固定拍摄，通过面板内容变化自然衔接，无硬切。

【特效规范】
禁止：仙侠发光、光剑光刃、金光粒子尾迹、水墨字发光、霓虹光晕、人工色彩叠加特效。
允许：主角护目镜眼部白色发光（角色固有设计，如LED冷白光，不闪烁不脉动）、虚拟面板的半透明暖白色柔光浮现与消退（模拟磨砂玻璃质感）、面板变红时的红色脉动光纹（暗红色，不刺眼，如警示灯般低频脉动）、面板文字浮现与变换（深灰色/红色无衬线字体，不发光，如印刷般沉稳）。

总时长：8s

# 第二部分：逐段批注（为什么这么写）

## 【禁止项】

四件套齐全，且补了「仅保留环境音效与人物台词」。
这句替代项很关键——只说"无BGM"会让模型把整个声音层关掉，人物台词和环境音也一起没了。

## 【风格定调】

| 行 | 妙处 |
|----|------|
| 视觉风格 | "无人工补光痕迹"这句话堵死了模型自动加轮廓光的习惯 |
| 摄影规格 | "轻微欠曝，保留暗部细节"是一组对抗指令：欠曝给出胶片感，保留暗部细节防止暗部糊死。两者缺一都会走偏 |
| 色彩基调 | **"阴影偏棕绿"是整段最值钱的一句**。没有它，暗部会发灰发死，整片立刻掉档次 |
| 特效禁令 | 先给黑名单，第 7 段再给白名单，形成夹逼 |

## 【角色 / 道具 / 场景引用】

- `img:0` 场景、`img:1` 角色，槽位号全片唯一
- "虚拟面板 暂无参考图"——无图也占一行，避免空槽位被当成自由发挥
- "暂无音频"明确了音色未定，模型不会自己编一个音色导致后续片段音色打架

## 【全局前置条件】

空间关系那句是防穿帮的核心，四要素齐全：

| 要素 | 原文 |
|------|------|
| 人物站位 | 巷弄中段偏右位置 |
| 人物朝向 | 面朝巷弄纵深方向 |
| 目标物位置 | 左侧青砖墙面为主角正前方，虚拟面板将浮现于该墙面上 |
| 光源方向 | 巷弄上方天光漫射，无明确方向性直射光 |

后面四个镜头的机位描述**全部引用这套坐标系**：
- 镜头1「主角斜后方」 → 相对人物位置
- 镜头2「从斜后方缓慢推近」 → 沿用镜头1的方位，只改距离
- 镜头3「主角侧前方」 → 跨到另一侧，用人物做锚点
- 镜头4「机位保持不变」 → 直接锚定镜头3

这就是多镜头不穿帮的做法：**每个机位都以空间坐标系里的某个点为参照，而不是凭空描述。**

## 【镜头描述】

**时间轴**：0–2 / 2–3.5 / 3.5–6 / 6–8，连续无缝，末镜 8s = 总时长。
最短一镜 1.5s（镜头2），刚好卡在安全边界上——再短模型就来不及完成转头动作。

**叙事节奏**（三段式，值得复用）：
```
镜头1 起：面板浮现（建立悬念，主角不回应）
镜头2 承：主角转头（建立人与面板的关系）
镜头3 转：面板变红报警（冲突峰值）
镜头4 合：恢复"任务完成"（反转收尾）
```
8 秒讲完一个完整的小反转，靠的是**信息递进**而非镜头堆砌。

**每个镜头的环境音都在变化**，这是隐式的镜头边界信号：

| 镜头 | 声音层 |
|------|--------|
| 1 | 风声 + 枯叶沙沙 + 极轻电流嗡声 |
| 2 | 金属摩擦声 + 低频嗡声 + 风声 |
| 3 | 电子警示音 + 心跳般嗡鸣 + 金属紧绷声 |
| 4 | 轻柔提示音 + 嗡声渐弱 + 风声回归 |

注意镜头4的声音是**回归镜头1**（风声+枯叶），形成声音闭环，暗示"一切恢复如常"。

**画面内容内部顺序**（每镜都一致）：
```
主体动作 → 环境材质细节 → 光影色彩 → 颗粒/质感收尾
```
例镜头3：面板文字变化（主体）→ 青砖墙被染暖色（环境）→ 冷暖对比（光影）→ 胶片颗粒柔和覆盖（质感收尾）。
每个镜头末尾都复述一遍"胶片颗粒柔和覆盖全画面 + 整体低饱和高明度"，是防止风格漂移的**重复锚定**手法。

## 【转场方式】

- 镜头1→2 用 Match Cut，承接动作是"转头"：镜头1末尾主角静止，镜头2开头"缓缓将头转向"，动作跨镜连续
- 镜头2→3、3→4 声明"同一机位固定拍摄""无硬切"，把变化交给画面内的面板内容
- 每个转场都写明了**靠什么承接**，不是只丢一个术语

## 【特效规范】

双清单夹逼，允许清单每项都带三件套：

| 允许的特效 | 理由 | 质感参照 | 动态约束 |
|-----------|------|---------|---------|
| 护目镜白色发光 | 角色固有设计 | LED冷白光 | 不闪烁不脉动 |
| 面板暖白柔光 | 磨砂玻璃质感 | 磨砂玻璃 | 浮现与消退（渐变） |
| 红色脉动光纹 | 警示状态 | 警示灯 | 暗红色、低频脉动 |
| 文字浮现变换 | 信息载体 | 印刷品 | 不发光 |

**"不闪烁不脉动"和"低频脉动"是分开的**——角色固有发光恒定，状态警示才脉动。这个区分避免了全片发光元素一起闪的廉价感。

# 第三部分：改造复用指南

## 同结构换皮（最快）

保留八段骨架与时间轴，替换这三项即可：

| 替换项 | 本例 | 你的版本 |
|--------|------|---------|
| 场景 | 青砖巷弄（img:0） | [你的场景] |
| 被摄物 | 虚拟面板（道具） | [屏幕/信件/水面/装置] |
| 三段式叙事 | 浮现→凝视→报警→恢复 | [起→承→转→合] |

### 换皮示例：把"虚拟面板"换成"水面倒影"

- 镜头1：水面浮现一层半透明微光 → 环境音改为水波轻响
- 镜头2：主角低头凝视水面 → 环境音加入衣料摩擦
- 镜头3：倒影扭曲变红 → 环境音为水下低频轰鸣
- 镜头4：倒影恢复平静 → 环境音回归水波轻响

骨架一字不改，只换被摄物与声音层。

## 延长到 10–15s

在两个位置插入镜头，不要平均拉长：
1. **镜头1 前加一镜建立镜头**（0–2s 空巷全景），后移时间轴
2. **镜头3 内拆两镜**（文字浮现一镜、变红脉动一镜），把冲突拉长

## 需要人物说话时

本例全程无台词，只有环境音。若要加台词：
1. 【禁止项】改为：`无字幕、无水印、无LOGO、无BGM，仅保留环境音效与人物台词。`
2. 对应镜头的**环境音行**追加台词行：
   ```
   台词："任务……失败了。"（语速缓慢，尾音下沉，音量偏轻）
   ```
3. 该镜头内部套用流程一的八维公式（目的/情绪/触发词/AU/眼神身体/声音/呼吸停顿）

## 常见改造坑

| 想改什么 | 别这么改 | 要这么改 |
|---------|---------|---------|
| 换时间（白天→夜晚） | 只改【全局前置条件】的时间行 | 时间行 + 环境行 + 色彩基调 + 每镜光影描述，四处一起改 |
| 加一个镜头 | 直接插入，时间轴照抄 | 插入后**重排全部时间码**，末镜对齐总时长 |
| 换主角服装 | 只在镜头1写 | 改【全局前置条件】空间关系行（那里写着"身着黑白机械装甲"） |
| 让面板一直红着 | 删掉镜头4 | 保留镜头4 但改内容为"红色持续低频脉动，画面渐暗"，维持声音闭环 |
