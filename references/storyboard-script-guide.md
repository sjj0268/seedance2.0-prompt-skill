# 多镜头分镜脚本生成指南（八段式 · 单段 ≤15s）

> 本指南覆盖单段内多镜头分镜脚本的写法。时长档位为 **5–15s**，
> 默认按 **10s** 出稿。

## 一、它解决什么问题

单次生成内让模型**自己切多个镜头**，同时保证：镜头之间不穿帮、风格不漂移、不出字幕水印 BGM、特效不越界。

### 与「三层架构表演提示词」的分工

| 维度 | 三层架构（流程一） | 八段式分镜脚本（流程二） |
|------|-------------------|-------------------------|
| 镜头数量 | 单个长镜头为主 | 一次生成内切 2–6 个镜头 |
| 核心控制对象 | 人物表演、情绪递进、台词 | 镜头调度、空间一致性、视觉风格 |
| 时间粒度 | 情绪节点，2–4 秒一段 | 镜头时间码，1.5–3 秒一镜 |
| 一致性靠什么 | 人物资产图 + 内置风格库 | **文字空间坐标系** + 资产引用槽位 |
| 适用场景 | 情感戏、对白戏、短表演 | 概念短片、UI/面板演示、氛围片段、转场密集的画面 |
| 输出长度 | 常见 5–15 秒 | 常见 5–15 秒 |

> 一句话区分：**三层架构管"人怎么演"，八段式管"镜头怎么切 + 画面长什么样"。**
> 两条流程可叠加：先用八段式搭骨架，其中需要表演的镜头内部再套八维公式。

---

## 二、八段式结构总览

严格按此顺序书写，顺序本身就是优先级：

| 段序 | 段落名 | 作用 | 能否省略 |
|------|--------|------|----------|
| 1 | 【禁止项】 | 掐掉模型默认添加的冗余元素 | 否 |
| 2 | 【风格定调】 | 锁定视觉风格、摄影规格、色彩基调 | 否 |
| 3 | 【角色 / 道具 / 场景引用】 | 绑定参考图槽位 | 无图时写"暂无参考图" |
| 4 | 【全局前置条件】 | 钉死时间、环境、**空间坐标系** | 否 |
| 5 | 【镜头描述】 | 逐镜写机位 / 画面内容 / 环境音 | 否 |
| 6 | 【转场方式】 | 说明镜头之间如何衔接 | 否 |
| 7 | 【特效规范】 | 禁止清单 + 允许清单 | 否 |
| 8 | 【总时长】 | 收口，与末镜时间码对齐 | 否 |

---

## 三、逐段写法详解

### 第 1 段：【禁止项】

**必须放在全文最前面。** 模型对开头指令的服从度最高，把禁令前置能省掉大量废片。

标准四件套：

```
【禁止项】
无字幕、无水印、无LOGO、无BGM，仅保留环境音效与人物台词。
```

要点：
- **四件套一个都不能少**——漏掉"无BGM"，模型大概率自动配乐；漏掉"无字幕"，中文提示词极容易烧字幕进画面。
- **必须给出替代项**（"仅保留环境音效与人物台词"）。只写"无BGM"会让模型把声音层整个关掉，写上允许保留什么，它才知道该留什么。
- 若有额外禁令（如"禁止出现现代建筑""禁止人物开口"），在此段追加。

---

### 第 2 段：【风格定调】

固定拆成四小项，缺一项风格就会漂移：

```
【风格定调】
视觉风格：日系清新胶片风，静谧自然生活感。画面柔和，颗粒质感明显，自然光为主，无人工补光痕迹。
摄影规格：35mm胶片模拟，16:9画幅，固定机位或极缓慢推拉，轻微欠曝，保留暗部细节。
色彩基调：暖黄米白为主色调，阴影偏棕绿，高光不过曝，整体低饱和、高明度，如午后阳光透过窗帘。
特效禁令：禁止数字光效、霓虹光晕、人工色彩叠加特效。
```

| 小项 | 必须回答的问题 | 常见的坑 |
|------|---------------|---------|
| 视觉风格 | 什么流派、什么情绪、画面质感如何 | 只写"电影感"——太抽象，模型无法执行 |
| 摄影规格 | 焦段、画幅、机位运动、曝光倾向 | 不写曝光倾向，默认会拍成高对比数码味 |
| 色彩基调 | 主色、阴影色、高光处理、饱和/明度 | 不写阴影偏色，暗部会发灰发死 |
| 特效禁令 | 明确禁掉哪些数字特效 | 只写"无特效"，会把角色固有发光也一起禁掉 |

**关键技巧**：色彩基调一定要写**阴影偏什么色**。只说主色调，暗部会失去色彩倾向，整段画面立刻掉档次。

---

### 第 3 段：【角色 / 道具 / 场景引用】

对应平台的多图参考槽位（`img:0` / `img:1` / `img:2`…）：

```
【角色 / 道具 / 场景引用】
角色参考：
主角 img:1，暂无音频 作为主角音色参考。
道具参考：
虚拟面板 暂无参考图
场景参考：
青砖巷弄 img:0
```

写法规则：
1. **每类资产单独起行**，写明类型（角色 / 道具 / 场景）+ 名称 + 槽位号。
2. **有图写槽位号，无图写"暂无参考图"**——不要留空。空槽位会被模型当成"自由发挥"。
3. **缺音频要明确写"暂无音频"**，否则模型会自己编一个音色，导致多段之间音色不统一。
4. 槽位号**全片唯一**，`img:0` 指到哪张图，后面每个镜头提到它都指同一张。

---

### 第 4 段：【全局前置条件】

**这是整套模板的灵魂，也是最容易被跳过的一段。** 拆成三项：

```
【全局前置条件】
时间：午后，阴天，天光柔和漫射。
环境：中式传统青砖巷弄，两侧高耸砖墙墙面斑驳带水渍痕迹，地面平整石板散落几片枯叶，
巷底隐约可见绿色树丛。自然漫射光均匀笼罩整条巷弄，无直射阳光，整体灰绿暖灰色调，
空气安静湿润，胶片颗粒均匀覆盖画面。
空间关系：主角身着黑白机械装甲站立于巷弄中段偏右位置，面朝巷弄纵深方向；
左侧青砖墙面为主角正前方，虚拟面板将浮现于该墙面上；光源来自巷弄上方天光漫射，
无明确方向性直射光。
```

| 子项 | 写什么 | 为什么必须写 |
|------|--------|-------------|
| 时间 | 时段 + 天气 + 光的性质 | 决定全片色温与光比，不写则每个镜头的光都可能不一样 |
| 环境 | 场景实体、材质、光效、色调、颗粒 | 给模型一个"世界底稿"，后续镜头只写变化部分 |
| **空间关系** | 谁站哪、面朝哪、被摄物在哪面墙、光从哪来 | **多镜头不穿帮的唯一保障** |

**空间关系为什么最关键**：单次生成内切多镜头时，模型没有持久的空间记忆，每个镜头都是"重新想象"一次。只有在这里用文字钉死一个坐标系（人物站位 → 朝向 → 目标物位置 → 光源方向），后面每个镜头引用它（"主角斜后方""主角侧前方""左侧墙面"），镜头之间才对得上。

**写法公式**：
```
[人物] + 站位 + 朝向 ； [目标物] + 所处位置 ； 光源来自 + 方向 + 光质
```

---

### 第 5 段：【镜头描述】

每个镜头固定用**四行结构**，一行都不能少：

```
【镜头1 · 0–2s · 固定中景 · 虚拟面板浮现于青砖墙面】
机位架设于主角斜后方约两步距离，固定中景拍摄巷弄纵深与主角背影侧面。
画面内容：斑驳的青砖墙面上，一片半透明白色光面缓缓浮现……
环境音：巷弄深处隐约的风声、枯叶被微风吹动的沙沙声、面板浮现时极轻的电流嗡声。
```

**标题行格式**：
```
【镜头N · 起止秒 · 景别/运动 · 一句话内容概括】
```
- 时间码用**累计秒**（`0–2s`、`2–3.5s`），不用 `00:00-00:02`
- 景别与运动合并写：`固定中景` / `缓慢推近中近景` / `固定近景`
- 一句话概括控制动作——模型会把它当成这个镜头的任务书

**四行结构解析**：

| 行 | 内容 | 作用 |
|----|------|------|
| 机位行 | 机位相对人物/场景的位置 + 景别 + 拍摄对象 | 呼应第 4 段的空间坐标系 |
| 画面内容 | 主体动作 + 环境细节 + 光影 + 颗粒 | 画面本体 |
| 环境音 | 该镜头的声音层 | **给模型一个隐式的镜头边界信号** |

**环境音必须逐镜单独写**，不要写一条全局环境音。理由有二：
1. 镜头切换时声场要跟着变，统一写会导致音画脱节；
2. 逐镜写"环境音"相当于给每个镜头打了结束标记，模型更容易识别镜头边界，切镜更利落。

**画面内容内部顺序**（建议固定，保证不遗漏）：
```
主体动作 → 环境/材质细节 → 光影与色彩 → 颗粒/质感收尾
```

### 第 6 段：【转场方式】

```
【转场方式】
匹配剪辑（Match Cut）：镜头1至镜头2通过主角头部转动的动作连贯性自然过渡；
镜头2至镜头3、镜头3至镜头4均为同一机位固定拍摄，通过面板内容变化自然衔接，无硬切。
```

可选项：

| 转场类型 | 适用情况 | 写法要点 |
|----------|---------|---------|
| **匹配剪辑 Match Cut** | 相邻镜头有同一连续动作 | 必须在两个镜头里都描述这个动作（前一镜"开始转头"、后一镜"转头完成"） |
| **同机位内容变化** | 机位不动，靠画面内元素变化推进 | 写明"同一机位固定拍摄"，并声明"无硬切" |
| **景别跳切** | 需要节奏冲击 | 写明跨度（中景→特写），并说明动机 |
| **淡入淡出** | 时间流逝、段落分隔 | 慎用，AI 视频里容易生成成灰场过渡，显廉价 |

**核心原则**：写明「为什么要这样转」。只写"匹配剪辑"四个字没用，要把**承接动作**点出来，模型才知道在哪一帧切。

---

### 第 7 段：【特效规范】

**必须写成「禁止 + 允许」双清单**——这是这套模板最实用的一条技巧。

```
【特效规范】
禁止：仙侠发光、光剑光刃、金光粒子尾迹、水墨字发光、霓虹光晕、人工色彩叠加特效。
允许：主角护目镜眼部白色发光（角色固有设计，如LED冷白光，不闪烁不脉动）、
虚拟面板的半透明暖白色柔光浮现与消退（模拟磨砂玻璃质感）、
面板变红时的红色脉动光纹（暗红色，不刺眼，如警示灯般低频脉动）、
面板文字浮现与变换（深灰色/红色无衬线字体，不发光，如印刷般沉稳）。
```

**为什么要给「允许」清单**：
只写禁止，模型不知道边界在哪——它要么把所有发光全掐掉（画面死板），要么照旧乱加（禁令失效）。给出允许清单，模型就有了明确的"可达区域"。

**允许清单的写法公式**：
```
[特效名称]（[为什么允许]，[质感参照]，[动态约束]）
```
- 为什么允许：角色固有设计 / 材质模拟 / 状态提示
- 质感参照：如LED冷白光 / 磨砂玻璃 / 警示灯
- 动态约束：**不闪烁不脉动 / 低频脉动 / 缓慢消退** —— 一定要写，否则模型会让所有发光元素一起闪，画面立刻变廉价

---

### 第 8 段：【总时长】

```
总时长：10s
```

- 单独一行收口
- **必须等于最后一个镜头的结束秒数**，模型会拿这个数校验时间轴
- **本技能口径**：用户指定了时长 → 写用户值（≤15s）；用户没指定 → 写 10s

---

## 四、时间码与镜头配比（本技能档位）

| 总时长 | 建议镜头数 | 单镜头时长 | 说明 |
|--------|-----------|-----------|------|
| 5s | 2–3 | 1.5–2.5s | 极限短，最多 3 镜 |
| 8s | 3–4 | 1.5–2.5s | 甜点区，范例即此档 |
| 10s | 4–5 | 2–2.5s | **默认档** |
| 12s | 4–5 | 2.5–3s | 用户指定时的常见档 |
| 15s | 5–6 | 2–3s | 单段上限，再多模型会丢镜 |

**硬边界**：
- 单镜头**不得短于 1.5s**：低于此值模型来不及完成切镜，两个镜头会糊成一团动作
- 单镜头**超过 4s** 时，该镜头内部应改用流程一的八维公式写表演，否则画面会空转
- **单段上限 15s**。用户要超过 15s → 按叙事节拍拆成多段独立提示词，每段各自闭环，本指南不管拼接

## 五、风格预设库（可直接复制）

```

摄影规格：35mm胶片模拟，16:9画幅，固定机位或极缓慢推拉，轻微欠曝，保留暗部细节。
色彩基调：暖黄米白为主色调，阴影偏棕绿，高光不过曝，整体低饱和、高明度，如午后阳光透过窗帘。
特效禁令：禁止数字光效、霓虹光晕、人工色彩叠加特效。
```

### 预设 B：冷调赛博夜景

```
【风格定调】
视觉风格：赛博朋克写实风，潮湿冷峻的都市夜景。画面锐利，雨雾感明显，霓虹环境反射，浅景深。
摄影规格：50mm镜头，16:9画幅，手持微晃与缓慢横移结合，正常曝光，高光溢出受控。
色彩基调：青蓝为主色调，阴影偏靛紫，高光偏品红，整体中低饱和、低明度，如雨后街面反光。

```

```
【风格定调】
视觉风格：90年代港产片质感，粗粝生活流。画面偏暖，颗粒粗大，实景自然光加少量钨丝灯补光。
摄影规格：35mm胶片模拟，16:9画幅，肩扛轻微晃动，轻微过曝，暗部压死。

特效禁令：禁止数字光效、慢门拖影、LUT式色彩断层、面部磨皮。
```

## 六、检查清单

生成前逐项核对：

- [ ] **总时长 ≤15s，且等于用户指定时长（未指定则为 10s）**
- [ ] 【禁止项】四件套齐全（无字幕/无水印/无LOGO/无BGM），且给出了允许保留项
- [ ] 【风格定调】四项齐全（视觉风格/摄影规格/色彩基调/特效禁令）
- [ ] 色彩基调写明了**阴影偏色**
- [ ] 【资产引用】每类都有槽位号或"暂无参考图"，无空槽位
- [ ] 缺音频时明确写了"暂无音频"
- [ ] 【全局前置条件】含时间/环境/**空间关系**三项
- [ ] 空间关系写全了：人物站位 → 朝向 → 目标物位置 → 光源方向
- [ ] 每个镜头标题行格式统一：`【镜头N · 起止秒 · 景别/运动 · 概括】`
- [ ] 时间码连续无断层，末镜结束秒 = 总时长
- [ ] 单镜头时长均 ≥ 1.5s
- [ ] 每个镜头都有独立的**机位行 / 画面内容 / 环境音**
- [ ] 画面内容覆盖：主体动作 → 环境材质 → 光影色彩 → 颗粒
- [ ] 【转场方式】点明了承接动作或"同机位无硬切"
- [ ] 【特效规范】含**禁止 + 允许**双清单
- [ ] 允许清单中每个特效都带动态约束（不闪烁/低频脉动/缓慢消退）

## 七、完整空白模板

```
【禁止项】
无字幕、无水印、无LOGO、无BGM，仅保留环境音效与人物台词。

【风格定调】
视觉风格：[流派]，[情绪基调]。[画面质感]，[光源性质]。
摄影规格：[焦段]，[画幅]，[机位运动]，[曝光倾向]，[暗部处理]。
色彩基调：[主色调]，阴影偏[色]，高光[处理]，整体[饱和度]、[明度]，如[具象参照]。
特效禁令：禁止[特效1]、[特效2]、[特效3]。

【角色 / 道具 / 场景引用】
角色参考：
[角色名] img:[N][，暂无音频]
道具参考：
[道具名] img:[N] 或 暂无参考图
场景参考：
[场景名] img:[N]
```

## 八、常见失败与修法

| 症状 | 原因 | 修法 |
|------|------|------|
| 画面烧进字幕 | 未写"无字幕"，或写在段落中间 | 提到【禁止项】第一位，并写"仅保留环境音效与人物台词" |
| 自动配了 BGM | 同上 | 同上；已生成的话用去 BGM 工具处理 |
| 镜头之间穿帮（人忽左忽右） | 空间关系没写 / 写得太简 | 补全第 4 段空间关系四要素，镜头机位行显式引用它 |
| 只切了 2 个镜头，后面的丢了 | 单镜头太短或总镜数超上限 | 单镜头拉到 ≥1.5s，总镜数压到配比表范围内 |
| 发光元素全在闪 | 允许清单缺动态约束 | 给每个允许特效补"不闪烁不脉动/低频脉动/缓慢消退" |
| 发光被全禁，画面死板 | 只写了禁止清单 | 补允许清单，说明哪些是角色固有设计 |
| 风格每个镜头都在变 | 色彩基调缺阴影偏色 | 补"阴影偏X色"，并在每个镜头末尾重复一遍色调 |
| 转场生硬像硬切 | 转场段没写承接动作 | 在相邻两镜中重复描述同一个连续动作 |
| 总时长超过 15s | 未按单段口径收口 | 收口只认 5–15s；默认 10s |
