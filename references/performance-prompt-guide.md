# AI表演类视频提示词生成指南（单段 ≤15s）

> 本指南覆盖单段表演/情感/对白类视频的提示词写法。
> 时长口径：**默认 10s，用户指定才改，硬上限 15s**。

## 核心原则

> AI 看不见人物的心理羞愧，但它能看见羞愧在脸上和身体留下的证据。

所有提示词必须将抽象情绪转化为**可观测的外在动作**。禁止使用空泛形容词（如"非常悲伤""极度愤怒"），必须具象化到面部五官、肢体、声音、呼吸的具体变化。

---

## 三层提示词结构

按以下三层顺序编写，每层职责明确，不可混淆。

### 第一层：全局控制层

负责视频整体参数，优先使用工具内置风格库，预留篇幅给表演描述。

必须包含：
- **时长**：明确秒数（**默认 10 秒，上限 15 秒**；仅用户明确指定时长时才偏离默认值）
- **比例**：横屏 16:9 / 竖屏 9:16
- **场景**：环境、时间、光线
- **人物一致性**：角色外貌、服装、年龄特征、音色
- **影像风格**：优先选用内置风格库（电影色调、影像风格），无需大段描述视觉参数

### 第二层：镜头时间轴层

按镜头分级 + 时间码子集编写，不可仅标注时间码。单段通常 **1–3 镜**。

必须包含：
- 各镜头的**时间区间**（如 0–4s、4–10s）
- 每个镜头的**拍摄主体**
- **视角切换节点**（何时切镜、切到什么角度）
- 镜头运动方式（推/拉/摇/移/固定）

### 第三层：表演控制层

决定 AI 演员表演效果的核心层，需最精细。

必须包含：
- 人物**动作**的具体描述
- **情绪变化**的时间节点和递进逻辑
- **台词触发节点**（哪句台词触发什么表情变化）
- **停顿换气**要求
- 说话前后的状态差异

## 八维表演万能公式

完整的 AI 表演提示词必须覆盖以下 8 个维度，按此顺序组织：

| 维度 | 说明 | 示例 |
|------|------|------|
| 1. 时间段 | 该段表演的时间区间 | 0–4s |
| 2. 人物目的 | 角色此刻想要什么 | 试图证明自己的牺牲是值得的 |
| 3. 情绪变化 | 从什么状态过渡到什么状态 | 从强硬反击到声音首次破裂 |
| 4. 台词触发词 | 哪句台词触发表情变化 | 说到"我做的一切"时 |
| 5. 面部动作与 AU | 具体五官动作 + AU 校准 | 眉毛内侧抬起(AU1, B级)，嘴角下压(AU15, C级) |
| 6. 目光和身体 | 视线方向 + 肢体动作 | 目光从对方脸上移开，肩膀微微下沉 |
| 7. 声音 | 音量、音色、语速变化 | 音量抬高后突然放轻，尾音颤抖 |
| 8. 呼吸停顿 + 结束状态 | 换气节点 + 说完后的静止反应 | 说完后停顿1秒，深呼吸一次，嘴唇微张未合上 |

> **停顿不是没有表演，而是人物心里的声音暂时超过了嘴里的声音。**

## 情绪节拍拆解方法

### 为什么需要拆解

AI 倾向于直接从情绪 A 跳转到情绪 B，缺少过渡。真实人类情绪是渐进的：先靠某种情绪自我保护，保护层逐步失效后，才流露底层情绪。

### 拆解步骤

1. 将单段按时间划分为情绪节点：**10s 片建议 2–3 个节点，每节点 2–4s**（15s 片最多 4 个）
2. 为每个节点定义：**表层情绪 → 底层情绪 → 触发事件**
3. 确保相邻节点之间有逻辑递进，不可跳跃
4. 节点要**少而密**——短时长里每个节拍只有一次"变化机会"，选最有张力的那次

### 示例：10 秒强硬→破裂递进

| 时间 | 节点 | 表层情绪 | 底层情绪 | 触发 |
|------|------|----------|----------|------|
| 0–4s | 反击 | 强硬 | 恐惧被看穿 | 对方的指责 |
| 4–7s | 裂缝 | 音量抬高后颤抖 | 委屈开始涌出 | 列举付出却无人回应 |
| 7–10s | 破裂 | 近乎羞耻的放轻 | 悲伤突破防线 | 意识到无法说服 |

> 同样的"愤怒→悲伤"弧线，长版能走五个节拍，10s 版只保留三个：
> **反击 → 裂缝 → 破裂**。砍节拍不砍递进逻辑。

## 表情与台词融合方法

### 常见错误

仅标注"情绪 + 台词"，二者无实质关联：
```
❌ 女人非常悲伤，眼泪直流，说："我撑不下去了。"
```

### 正确方法

将**台词作为表情变化的时间轴**，明确标注：

1. **说话前状态**：开口前的表情和身体姿态
2. **触发变化的台词节点**：具体哪个词/哪句话触发表情变化
3. **重音位置**：哪个字/词需要加重
4. **对应肢体眼神动作**：说话时手、眼、身体在做什么
5. **呼吸停顿**：句间换气、句末停顿
6. **说完后状态**：台词结束后的静止反应

### 示例

```
✅ 说话前：女人紧抿嘴唇，下巴微抬，目光直视对方，双手握拳在身侧。
   说到"我做的一切"时：音量抬高，眉毛下压(AU4, B级)，身体微微前倾。
   说到"为了你"时：声音突然放轻，尾音颤抖，目光从对方脸上移开，
   拳头松开，手指微微蜷缩。
   说完后：停顿1秒，深呼吸一次，嘴唇微张未合上，肩膀下沉。
```

### 台词量校验

单段台词字数 ≈ **4.5 字/秒 × 有效说话时长**：
- 10s 片有效说话约 5–6s → 台词 **不超过 25–30 字**
- 15s 片有效说话约 8–10s → 台词不超过 35–45 字
- 超了就砍台词或改写更短，**不要指望模型加速念完**——加速 = 表演全毁

## AU 辅助校准规范

### 什么是 AU

AU（Action Unit）源自面部动作编码系统（FACS），将表情拆解为可观测的面部动作单元。每个 AU 对应一组特定肌肉的运动。

### 使用规则

1. **AU 是辅助校准，不是情绪公式**：必须先写自然语言描述的可见动作，再用 AU 做校准
2. **强度标注**：按 A-E 级标注动作强度（A=微弱，E=最强）
3. **三阶段描述**：专业表情需覆盖动作的**起始 → 峰值 → 消退**三阶段
4. **不可仅用 AU 代替自然语言**

### 常用 AU 速查

| AU 编号 | 动作 | 对应表情 |
|---------|------|----------|
| AU1 | 眉毛内侧抬起 | 悲伤、痛苦 |
| AU2 | 眉毛外侧抬起 | 惊讶 |
| AU4 | 眉毛下压聚拢 | 愤怒、专注 |
| AU5 | 上眼睑抬起 | 惊讶、恐惧 |
| AU6 | 脸颊抬起（眼轮匝肌） | 真心微笑 |
| AU7 | 眼睑收紧 | 愤怒、厌恶 |
| AU9 | 鼻子皱起 | 厌恶 |
| AU10 | 上嘴唇抬起 | 厌恶、轻蔑 |
| AU12 | 嘴角向外拉伸 | 微笑 |
| AU15 | 嘴角下压 | 悲伤、不悦 |
| AU17 | 下巴抬起 | 困惑、悲伤 |
| AU20 | 嘴角横向拉伸 | 恐惧 |
| AU23 | 嘴唇收紧 | 愤怒、克制 |
| AU24 | 嘴唇压紧 | 愤怒、决心 |
| AU25 | 嘴唇分开 | 放松、说话 |
| AU26 | 下颌下垂 | 惊讶 |
| AU28 | 嘴唇吸吮/抿紧 | 焦虑、克制 |

## 具象化描述规范

### 面部五部位拆解法

将面部拆解为五个部位，依次记录每个部位的动作：

1. **眉毛**：方向（抬/压/皱）、内侧/外侧、强度
2. **眼睛**：睁开/闭合、视线方向、眨眼频率、泪光
3. **鼻子**：鼻翼张缩、皱鼻
4. **嘴巴**：嘴角方向、嘴唇开合、紧抿/颤抖、牙齿露出
5. **下巴/脸颊**：下巴抬起/收紧、脸颊抬起/肌肉紧绷

### 正反例对照

| 情绪 | 错误写法 | 正确写法 |
|------|----------|----------|
| 悲伤 | 女人非常悲伤，眼泪直流 | 眉毛内侧抬起，眼角含泪但未落，嘴角下压，下巴微颤，肩膀微微下沉 |
| 愤怒 | 男人愤怒大声咆哮 | 眉毛下压聚拢，眼睛瞪大，鼻翼张开，嘴唇紧抿后突然张开，音量抬高，身体前倾，双手握拳 |
| 恐惧 | 她很害怕地看着他 | 眼睛瞪大，眉毛抬起且聚拢，嘴角横向拉伸，呼吸急促，身体微微后退，双手在身前 |
| 羞耻 | 他感到羞愧 | 目光向下移开，头微微低下，脸颊肌肉紧绷，嘴唇抿紧，肩膀内收，手无意识地摸后颈 |
| 隐忍 | 他强忍着情绪 | 下颌肌肉绷紧，嘴唇压紧后松开，喉结上下滚动一次，呼吸放浅，双手垂在身侧握拳又松开 |
| 释然 | 她终于放下了 | 肩膀下沉两厘米，眉毛舒展，嘴角极轻微上扬，长呼一口气，目光从地面缓缓抬起 |

## 完整提示词模板（10s 默认）

```
【全局控制层】
时长：10秒，横屏(16:9)
场景：[环境描述，时间，光线]
人物：[角色外貌，服装，年龄，音色]
风格：[选用内置风格库名称]

【镜头时间轴层】
镜头1（0–4s）：[景别]，[拍摄主体]，[镜头运动]，[视角]
镜头2（4–10s）：[景别]，[拍摄主体]，[镜头运动]，[视角]

【表演控制层】
镜头2（4–10s）精细表演：

4–7s
- 人物目的：[角色想要什么]
- 情绪：从[状态A]到[状态B]
- 台词："[台词内容]"
- 说话前：[表情+身体姿态]
- 触发词"[具体词]"时：[面部动作(AU+强度)，眼神，肢体，声音变化]
- 重音："[字词]"
- 呼吸：[换气/停顿节点]
- 结束状态：[说完后的静止反应]

7–10s
- （同上结构）
```

> 15s 版：镜头时间轴扩到 2–3 镜，情绪节点最多 4 个，其余结构不变。

## 与八段式分镜脚本的衔接

当一段视频**既有多镜头切换、又有人物表演**时，用八段式搭骨架，需要表演的镜头内部再套八维公式。

### 衔接写法

在【镜头描述】的某个镜头内，把「画面内容」拆细为表演时间轴：

```
【镜头3 · 3.5–6s · 固定近景 · 主角看到失败提示后的反应】
机位架设于主角侧前方，固定近景拍摄面板全貌与主角侧脸。
画面内容：面板转为暗红，主角身体微微绷紧。

  3.5-4.5s 察觉
  - 人物目的：确认自己看到的不是误报
  - 情绪：从平静到警觉
  - 说话前：护目镜白光映出红光，头部微顿，肩膀上抬
  - 触发词"任务失"时：眉心收紧(AU4, B级)，呼吸顿住半拍，手指微微蜷缩
  - 呼吸：吸气后屏住，未呼出

  4.5-6s 绷紧
  - 人物目的：压住反应，不让自己失态
  - 情绪：从警觉到克制
  - 台词：（无台词，仅有呼吸声）
  - 面部动作：下颌肌肉绷紧(AU24, C级)，嘴唇压紧
  - 目光：锁定面板中心，不眨眼睛
  - 身体：披风垂落不动，双肩下沉后停住
  - 呼吸：缓慢呼气一次，气息偏重
  - 结束状态：身体维持紧绷，目光未移开

环境音：面板变红时短促的电子警示音、低频心跳般嗡鸣、装甲细微的金属紧绷声。
```

### 衔接要点

- **八段式管外层**：机位、景别、转场、特效、环境音、总时长
- **八维公式管内层**：人物的目的、情绪、AU、呼吸、声音
- 环境音行保持在**镜头层级**，不下沉到表演时间轴里
- 无台词的镜头也要写八维——人物目的和呼吸停顿依然成立

## 生成操作步骤

1. 打开小云雀 Agent（或支持 Seedance 系列模型的工具）
2. 选择模型：**Seedance 2.5 / 2.0 / 2.0 fast / 2.0 mini 均可**
3. 设置时长：**10 秒（默认）**；用户明确指定时长则按用户值，最高 15 秒
4. 设置比例：**横屏 16:9**（竖屏内容选 9:16）
5. 开启**原声**（如有台词）
6. 粘贴完整提示词
7. 提交生成

### 复用技巧

- 小云雀支持**提前预设提示词模板**，相同题材创作时直接调用复用
- 风格库配置可保存为预设，无需每次重新选择

## 常见失败与修法

| 症状 | 原因 | 修法 |
|------|------|------|
| 表情僵硬、面无表情 | 用了抽象情绪词 | 改用面部五部位拆解法，逐部位写动作 |
| 情绪瞬间跳转，很突兀 | 没有情绪递进 | 补中间节点，按"保护层逐步失效"重新拆节拍 |
| 台词和表情对不上 | 台词与表情未绑定 | 指定触发词，写清"说到X词时"发生什么 |
| 表情过度夸张像面具 | AU 强度给太高，或只堆了 AU | 强度降到 B-C 级，且必须先用自然语言描述动作 |
| 说完台词立刻静止像断电 | 缺结束状态 | 补"说完后"的静止反应与呼吸 |
| 说话像念稿没有起伏 | 缺重音与呼吸 | 标注重音字词与换气节点 |
| 台词念得飞快像赶稿 | 短时段塞了长台词 | 按 4.5 字/秒砍台词，或建议用户加时长 |
| 人物中途变脸 | 人物一致性描述不足 | 强化全局控制层的外貌/服装描述，或传入人物资产图 |
| 情绪弧线没走完就结束 | 10s 片照抄长片节拍表 | 节拍压缩到 2–3 个，砍中间档保首尾 |
